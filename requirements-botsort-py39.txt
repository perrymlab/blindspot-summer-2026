# BoT-SORT / FastReID runtime dependencies for the PRIME project (RESEARCHER ONLY)
#
# This is the dependency set required to run the patched BoT-SORT tracker
# (vendor/BoT-SORT, branch prime-reid-poison-export) end to end and export
# per-detection ReID embeddings. STUDENTS DO NOT NEED THIS -- they consume the
# exported CSVs with the project's own .venv (Python 3.12). See
# docs/botsort-integration/BOTSORT_GPU_RUNBOOK.md for the full researcher workflow.
#
# -------------------------------------------------------------------------
# REQUIREMENTS BEFORE INSTALLING THIS FILE
# -------------------------------------------------------------------------
# 1. Python 3.9 -- NOT 3.10+.
#    FastReID imports `collections.Mapping`, which was removed in Python 3.10.
#    Create an isolated env:
#        conda create -y -n botsort python=3.9
#        conda activate botsort
#
# 2. PyTorch is installed SEPARATELY (it is intentionally NOT listed below).
#    Its wheels come from a CUDA-specific index URL, which -- if put in this
#    file -- would override PyPI for every other package. Install these EXACT
#    versions first (do NOT use a bare `pip install torch` -- newer torch such
#    as 2.11/cu128 publishes NO Python 3.9 wheels and pip will fail or pull an
#    incompatible build):
#        pip install torch==2.5.1 torchvision==0.20.1 --index-url https://download.pytorch.org/whl/cu121
#    cu121 wheels are verified working on the box's newer driver/CUDA (CUDA
#    wheels are forward compatible with newer drivers).
#
# Then:  pip install -r requirements-botsort-py39.txt
# -------------------------------------------------------------------------
#
# These pins are the exact versions captured with `pip freeze` from the
# verified-working Python 3.9 `botsort` env (torch 2.5.1+cu121). numpy<1.24 and
# scipy<1.11 are not just a precaution -- the working env runs numpy 1.23.5 /
# scipy 1.10.1, and the 2021-era FastReID code breaks on the newer APIs.
# torch's own transitive deps (nvidia-*-cu12, triton) are intentionally omitted
# here; they install automatically with the torch step above.
